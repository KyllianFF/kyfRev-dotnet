# Bibliothèques reprises

Pour reproduire à l'identique le texte affiché par kyfRev 0.x, dont dépendent les positions des passages
déjà enregistrés, ce moteur reprend en C# le code des bibliothèques JavaScript ci-dessous. Leurs
licences s'appliquent à ces parties.

La table `Markdown/html5-entities.txt` provient de la norme HTML du WHATWG
(<https://html.spec.whatwg.org/>, licence CC BY 4.0).
